# 3dplus Tests

This folder carries the CPU 3D Twin test suite ported from `ai-desk/v2/3dplus`.

The implementation under test lives in the root `.verify.yume.js` files:

- `cpu3d.verify.yume.js`
- `animation.verify.yume.js`
- `collision.verify.yume.js`
- `ik.verify.yume.js`

Run it with:

```sh
npm run test:3dplus
```
