A11: Domain-Tagged Values

The LLM's "Type System" is the "Value" itself.

let pos = "world:5,0,2"; // OK
let amount = "usd:9.99"; // OK
let pos = [5, 0, 2]; // NG: Context-dependent
  • Context-Free Meaning: The value defines its own type/domain.
  • Linear Error Reduction: AI cannot confuse coordinate systems if they are baked into the strings.
  • Crystallization Friendly: Enables easy translation to static types like Go.
