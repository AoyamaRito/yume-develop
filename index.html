The Evolving Substrate

Crystallizing ai-desk into self-contained Blocks.

yume-develop is the next-generation workspace for AI-Native development, serving as the bridge where the core logic of ai-desk evolves onto the .yume.js foundation.

Here, code is history. Every file is an executable, append-only micro-repository that carries its own runtime, dependencies, and metadata. We are proving that human-era readability can be discarded in favor of AI-centric structural integrity.

Testing Philosophy

Axiom A14: Top-Down Verification.

AI-era testing must proceed from the whole to the part. Establish the gravitational field of context with End-to-End tests first, then let the AI autonomously fill the execution coverage gaps with unit tests.

1. Declare intent via E2E

Write an End-to-End scenario first. This gives the AI the complete picture of "what success looks like," preventing hallucination caused by bottom-up guesswork.

2. Implement to pass

The AI writes the necessary implementation to make the E2E scenario pass, establishing the primary logic paths.

3. Measure structural gaps

Execute the E2E test while collecting precise V8 coverage data (using coverage.verify.yume.js) to identify exactly which Blocks and branches were missed.

4. Autonomous Gap Filling

The AI reads the coverage report—not as an abstract metric, but as direct prompts indicating which specific code snippets require targeted unit tests to achieve 100% verification.

Core Assets

The Crystallized Core

All foundational logic from ai-desk v2 has been successfully migrated into the .yume.js format, complete with isolated histories and pinned runtimes.

core.module.yume.js

The pure logic for Block and Graph management. Zero external dependencies.

rules.constraint.yume.js

The Constraint Folding engine. Eliminating nested if/else statements by evaluating all possible worlds against declarative filters.

coverage.verify.yume.js

A native wrapper around node:inspector that executes functions and returns precise V8 coverage data, feeding the Gap Filler loop.

cpu3d.verify.yume.js

The Double-Entry Math implementation. A CPU Twin running alongside WebGL to definitively prove whether a 3D bug is logical or visual.

eyes.debugger.yume.js

The Coma-Okuri Debugger. Generates frame-by-frame HTML replay logs from draw operation streams, enabling visual verification without a browser.
