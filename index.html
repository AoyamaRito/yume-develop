yume-develop

The evolved substrate for AI-Native development. Moving beyond central indexes to self-contained code-cells.

Evolution from ai-desk

yume-develop takes the core principles of ai-desk v2 (All-as-Block, Versions-as-Body) and physicalizes them into the .yume.js (BLOCKFILE) format.

Self-Contained

Every file carries its own history, refs, and metadata. No external graph.json needed for the source of truth.

Runtime Pinning

Each file specifies its own runtime version, ensuring it remains executable for years to come.

Top-Down E2E

Axiom A14: Establish context via E2E first, then let AI fill coverage gaps with unit tests.

Axiom A14: Top-Down Verification

"AI時代のテストは、必ず『全体から部分へ』向かって書け。
E2Eテストで文脈の重力場を形成し、その実行カバレッジの隙間を
単体テストで自律的に埋めよ。"

This is the first repository dedicated to the Top-Down workflow, enabled by the coverage.verify.yume.js engine.
